name: website-audit
description: Audits a website or web UI for clutter, weak hierarchy, duplicate messaging, redundant sections/cards/charts, and AI-generated patterns. Measures density before judging, and diagnoses only — changes nothing. Use when a page feels cluttered, bloated, busy or generic, or when asked to review, critique or audit a site's design.
---

Audit the site as a hostile creative director. **Diagnose only — change
nothing in this pass.** Praise is not the output; a prioritised problem
list is.

## First, measure. Do not audit from vibes.

Count, and state the numbers:

- sections, cards, distinct card *variants*, charts
- visible tabular rows
- controls (sliders, buttons, toggles)
- distinct font sizes
- **places "the answer" is stated** — the single most revealing metric

A page with nine card variants that are all "label, number, sub-label"
has one component and eight costumes. A page stating its answer six times
has no answer.

## Then check the framing

Before scoring, ask who this is actually for. Conversion/CTA/trust-signal
analysis is meaningless on a private dashboard or personal tool.
**Say so rather than inventing problems to fill a template.**

## What to look for

**Clutter** — repeated messaging, sections that restate each other,
everything rendered as a card, uniform grids, completeness bias (showing
all N because N exist).

**Hierarchy** — is there one thing per screen that dominates? Equal
spacing everywhere means nothing groups.

**AI-generated tells** — uniform card grids; every section explaining
itself with an identical subtitle; no section allowed to be small;
symmetry everywhere; data shown because it was available.

**Story** — can a visitor say what this is in 5 seconds? Where does it
stop having a thesis and become an inventory?

## Output

1. Measured table (before-numbers)
2. Problems, each as: *Problem / Why it hurts / Recommended fix*
3. KEEP / REMOVE / MERGE / MOVE / REWRITE per section
4. "If I removed another 20%, what goes?"
5. Ranked top changes by impact ÷ effort

Identify what to protect, not just what to cut — a review that only
subtracts will strip the personality out along with the noise.
